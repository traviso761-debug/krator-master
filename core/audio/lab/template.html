Krator Audio Lab

The testbed for core/audio. Sort the catalogue by category, tag, license and length; mark each clip's status and note what it is for. Cut passages out of recordings and shape their sound, then layer them into scenes that render as seamless loops.

⚠️ Local file mode (file://): Browsers restrict Web Audio multi-tracking (Scene soundscapes, Cut editor, Reverse) on file:/// URLs. Switch to http://localhost:8080 (local server active) for full audio playback.

    Every clip here is public domain, CC0 or CC BY, so all of it can go into a game that is sold; CC BY clips say who to credit.     Cut

    Drag across the waveform to select a passage; drag a selection edge to adjust it; click to place the cursor. Shape it with the sound controls below, then save it as a new clip, send it to the scene, or save it as a WAV. "Find loop points" moves the end of the selection to where the sound matches its start, so the cut repeats cleanly.

    Cues

    A cue is a sound the game asks for by name, like sfx.combat.hit.metal. It holds several variants and plays a different one each time, with a little random pitch and volume, never repeating the last few. Pick its variants below: the picker filters the Library by words, category, license, length and tags, Play auditions a clip and Add makes it a variant; "+ Cue" in the Library and "Add to cue" in Cut do the same. Then fire it to hear the variety.
