# kits/abyss-salvage: Abyssal Salvage Kit (Kenshi-Swamp Influenced)

Compact salvage-architecture kit for East Abyss hamlets, small marsh villages, and outer suburbs of
Mungo and Locus. Read in place via `abysssalvage.py` on the Locus/Yuni `ASSET` frame (zero extra draw calls;
reuses existing `corrugate`, `rust`, `plank`, `timber`, `bark`, `rubble`, and `glowmat` material families).

## Pieces (9)

- `swamp_dome_hall` (`18 x 18`): large patchwork riveted-plate saucer dome on cross-braced stilts, wrap-around catwalk, steep stair, braziers, guyed mast.
- `swamp_tavern_dome` (`16 x 16`): stilt salvage dome tavern with lit overhead signboard and flanking fire-braziers.
- `swamp_pod_hut` (`10 x 10`): small circular patchwork stilt pod with gabled entry hood.
- `swamp_shack_a` (`11 x 10`): elevated plank-deck lean-to salvage shack.
- `swamp_shack_b` (`13 x 10`): double-bay elevated stilt dwelling with split corrugated roof.
- `swamp_workshop` (`14 x 11`): elevated iron workshop/smokehouse with conical flue hood and triple exhaust vents.
- `swamp_storehouse` (`11 x 11`): tall windowless ribbed-iron stronghouse with exterior steel buttresses.
- `swamp_gatehouse` (`12 x 10`): timber-and-corrugate marsh watch-gate with blast shields and crow's-nest.
- `swamp_paddy_ring` (`16 x 16`): circular plank-and-corrugate walled marsh sump/paddy ring.
