Open Krator on another device

Use these on a phone, tablet or another computer in the same home.

  1. Connect the other device to the same Wi-Fi as the computer running Krator.
  2. Point its camera at a code below and tap the link that appears, or open Chrome and type the address under the code.
  3. Bookmark the page there, so next time is one tap.

These addresses work only on this network, and only while Krator is running on its computer. If one stops working, the router may have given that computer a new address: open this page again on it.
