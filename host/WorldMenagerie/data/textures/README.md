# data/textures

Texture sets for the engine's real surfaces (`C.surfaces`, `src/engine/stages/00-start.js`: `surface()`) and the tree
crowns' leaves (`C.foliage`, `03b-details.js`). Each is a 512 px WebP. A city names the ones it uses, with each set's mean
colour (the pattern is the texel over that mean, so the city's own colours stay) and its size in metres. Fort Worth is the
first city to use them (`data/cities/fortworth.json`).

Copied from Krator's material library (`core/materials/library/` in krator-master), downsized:
