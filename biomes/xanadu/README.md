# Krator biome — Xanadu (the Vale)

Recovered into the repo from the published artifact **Krator biome — Xanadu**
(https://claude.ai/artifact/MeL6TBE7cUn6X4o3UEyQ7Q, Sep 29 2026), which was built in another session and had no
source here. `src/` holds its fragments split at the page's `// ==================== NN-file.js` markers; the
host fragments (45, 46, 82–91) are the ideal-type stage and are not vendored by worlds. Worlds vendor 10–70.

The world that uses it: `../../settlements/xanadu/` (the Xanadu building kit and the city of Erewhon), which vendors 10–70 as
`src/86-bio-*` plus one additive export in 55 (`XANADU.treeAt`, a single tree of a named species at a point, for
gardens). The biome's own heightmap of the vale is a rough guide only; Erewhon's terrain comes from Travis's map.
