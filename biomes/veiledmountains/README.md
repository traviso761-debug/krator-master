# Veiled Mountains (`biomes/veiledmountains`)

Standalone 5-station biome kit for **The Veiled Mountains** (`rmwzq1pa88m7q`, `Veilpass`, `mist valley 2`, `mist valley`, `Region 177`; homeland of the unconquered **`Timpar-Kuran`** clans and ancestral **`Kanopi`** cradle of the `Utari-Kuran`).

## Commands

```bash
node biomes/veiledmountains/tests/test-veil.js
python3 tools/build.py biomes/veiledmountains --all
python3 tools/check_port.py biomes/veiledmountains
python3 biomes/veiledmountains/verify.py --assert --no-cache
```

## Stations (`dist/`)

1. **`hall`** (`dist/veiledmountains.html`): *The Hall of Veils & Giant Tree-Fern Floor* (`252, 668`, `+2,380 m`, `1.21 atm`)

3. **`kanopi`** (`dist/veiledmountains-kanopi.html`): *The Weeping Oculus of Kanopi* (`242, 752`, `+2,650 m`, `1.17 atm`, `KRUINS.watch`)
4. **`veilpass`** (`dist/veiledmountains-veilpass.html`): *Upper Veilpass U-Trough & the White Col* (`278, 842`, `+3,520–+5,400 m`, `1.05 atm`)
5. **`southvale`** (`dist/veiledmountains-southvale.html`): *The Hush-Edge Moss Labyrinth* (`228, 948`, `+2,880 m`, `1.14 atm`)
